# Dionysus

A home cocktail menu for a kitchen tablet. It shows the drinks you can make from the bottles you actually have.

- Four ways in: **by spirit**, **by feel** (sweet, balanced, bitter, decadent, spirit-forward, fresh), **Surprise me** (roll the dice) and **A–Z**.
- Search across names, spirits, flavours and ingredients, filtered to what you can make now or with one more bottle.
- Recipes readable from across the kitchen, with each step drawn as the bartender's own movement, and a story for every drink.
- **One bottle away** ranks the bottle that would unlock the most new drinks.

## Run it

Open `index.html` in a browser, or serve the folder: `python3 -m http.server`, then visit `http://localhost:8000`.
